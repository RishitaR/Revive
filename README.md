# Revive
Revive is a comprehensive and user-friendly application designed to connect drivers with authorized mechanics, offering timely and reliable roadside assistance, especially in remote areas. With integrated features such as real-time location tracking, service booking, and a dedicated mechanic portal, Revive ensures a seamless and efficient user experience during vehicle breakdown emergencies.

## Features
- **Location Tracking**: Enables users to share their exact location with mechanics for quick assistance.
- **Service Booking**: Allows users to book assistance services easily with detailed service descriptions and availability.
- **Booking History**: Maintains a record of all past service bookings for reference and transparency.
- **Mechanic Portal**: A dedicated interface for mechanics to view and manage service requests in real-time.
- **Reliable Assistance**: Connects drivers to authorized mechanics for quality and trusted services.

## Technologies Used
- **ReactJS**: For building the user-friendly web application interface.
- **Node.js**: Backend server for handling API requests and real-time interactions.
- **React Native**: For creating a cross-platform mobile application for iOS and Android.
- **MongoDB**: As the backend database to store user, mechanic, and service data securely.
- **CSS**: For designing a visually appealing and responsive user interface.
- **Expo**: For simplifying React Native development and deploying the mobile application.
